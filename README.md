# Clínica Élite Palma · Prototipo de rediseño web

Prototipo navegable para presentar al cliente ([elitepalma.com](https://www.elitepalma.com/)).
No es la web final: los datos de opiniones, cifras de Google, equipo y simulaciones están marcados como ejemplo.

## Ver el prototipo
Abre `index.html` en el navegador (no necesita servidor ni instalación).

## Estructura
- `src/elite.html` — fuente del prototipo (HTML + CSS + JS en un solo archivo).
- `build.sh` — genera `index.html` (documento completo) a partir de la fuente.
- `docs/investigacion.md` — referencias y funcionalidades seleccionadas.

## Funcionalidades incluidas
- Cabecera fija con CTA "Pedir cita", selector de idioma ES/EN/DE y modo claro/oscuro.
- Hero con arco mallorquín animado (mar al atardecer) e indicador de próximo hueco libre.
- Especialidades por pestañas: Dental, Medicina estética y Capilar.
- Simulador de blanqueamiento antes/después (arrastrable, escala VITA).
- Calculadora orientativa de injerto FUE (escala Norwood).
- Recorrido "Tu primera visita" en 5 pasos.
- Reserva online en 3 pasos (tratamiento → día y hora según horario real → datos) con confirmación.
- Equipo, opiniones con valoración de Google, calculadora de financiación, FAQ, mosaico de Instagram.
- Botón flotante de WhatsApp y asistente con respuestas rápidas.
